# Scheme Finder Pro

Build a simple multilingual web app named “SchemeMitra”.
Purpose

SchemeMitra helps users find eligible government schemes based on basic details and redirects them to official government websites.
The app is for awareness only and does not handle applications.

🔹 FIND MY SCHEMES – INPUT FORM

Fields:

Name (optional text)

Occupation (Student / Farmer / Worker / Unemployed)

Above ₹5L
